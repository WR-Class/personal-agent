# Personal Agent 界面接线清单

范围：本仓库独立 Electron 客户端，不是 DSH GUI。以能实际完成操作为「已接线」，跳转占位页、弹出未实现提示不算接通业务。下表结合代码审计与本轮 Electron 验收；第三方云端兼容性不在回环模拟服务验收范围内。

## 输入区统一设计

- 首页保留工作区选择；进入对话后不再展示文件夹选择和分隔底栏，权限移至输入框内左下角「＋」旁，模型与发送在右侧。已有会话的工作区绑定不因隐藏控件而改变。
- 「＋」只提供添加文本文件，不重复模型和权限的固定入口，也不直接打开工作区面板；没有未接通的占位指令。文本附件通过用户主动选文件读取，显示文件名、移除按钮与发送披露，点击发送后内容进入模型请求与历史。当前消息协议只支持文本，图片/PDF/二进制拒绝并说明，不宣称图像已传给模型。
- 模型、工作区和工具权限共用字号、按钮高度、圆角与主题色；首页目录展示短名，完整路径保留在提示中。模型菜单显示模型名与服务商，并支持搜索。
- 模型/权限使用应用主题的顶层弹出菜单，避免原生系统菜单样式割裂及被输入卡片裁切；支持方向键、Enter、Escape、Tab、点击外部关闭，深浅主题共用语义令牌。
- 隐藏的原生选择器仍是值与 change 事件的状态入口；可见控件不改权限授权、切换模型的历史转移确认或运行中禁用逻辑。敏感“完全访问”保留主进程确认。

- 提供商弹窗验收曾将 CDP 模拟视口设为 800px 高但未清除，而原生测试窗口为 900px；后续聊天因此在状态栏下留下约100px空白。现每次尺寸验收均在 finally 清除模拟，并在命令审批打开/结束时断言恢复原生视口、状态栏贴底；不通过产品 CSS 固定高度掩盖测试状态泄漏。

## 输入框下方会话用量

- 对话输入框下方居中展示已记录的轮次/模型步数、最近模型请求平均输出速度、累计 tokens、缓存命中率和上下文占比；右下角「用量未接线」已移除。运行/失败/附件提示保留在聊天消息区域，不覆盖用量行。
- tokens 与缓存计数来自提供商 usage，写入会话日志并在重开恢复；缺失值显示「—」，部分统计带「*」。速度包含请求网络与等待时间，不冒充纯生成速度。上下文窗口尚无可靠配置，因此上下文占比显示「—」，不照参考图虚构百分比。
- 失败发送后只读刷新历史用量，不自动重开会话或重置权限；新建会话清空统计。旧日志可读取，无用量的旧会话不展示假零值。

## 统一权限与发送/停止

- 首页与聊天输入框只保留一个发送按钮：请求中显示停止方块，即使输入已清空也可点击；停止后等待当前请求与会话作业清理完成才恢复发送，避免重叠请求。回复后仍有后台作业时，空输入保留停止入口；有草稿可继续发送，Esc 可停止后台作业。模型切换等无发送的忙状态禁用此按钮。运行中 Escape 取消整轮；审批弹窗的普通取消只拒绝当前操作。
- 删除独立停止按钮、检测工具按钮和模型文件工具开关；只有「只读 / 工作区写入 / 完全访问」三个权限档位。选择项目即默认提供文件读取工具，不需再次启用工具。
- 桌面与 CLI 共用核心工具工厂。只读提供读取、目录、inspect 与作业输出工具；工作区档增加文件写入、删除/重命名/批量工具以及模型命令、作业取消和会话任务状态。区内文件修改自动执行；命令因没有 OS 沙箱而逐次批准，不把进程工作目录冒充隔离。
- 完全访问需主进程明确确认，文件读写可越出根目录，模型命令和人工命令免逐次确认。文件工具仍执行受保护状态、敏感路径及链接检查，但任意命令拥有当前用户权限，这些文件检查不能限制命令。
- 权限升级仅当前窗口/工作区有效；模型切换保留当前权限，历史传给新服务仍须确认。重开历史、切换目录或刷新回到只读。请求和已完成文件操作不会因为停止而回滚，也不会自动新建聊天。
- 隔离回环验收覆盖实际鼠标点击统一按钮终止慢HTTP（服务端观察连接关闭）、停止后无后续模型/工具工作、原会话续聊；待审批时用原生 Escape 验证停止，不声称鼠标可穿透弹窗点击背后的发送按钮。

## 聊天布局与工具证据

- 真实聊天中用户消息右对齐、助手消息左对齐；不显示「你 / Personal Agent」角色标签，行级 `role=group` / `aria-label` 保留读屏区别。安全正文与多行错误仍使用原有文本/Markdown 渲染。
- 每次工具调用的参数与结果按 callId 合并为一个默认收起的原生 details 卡，摘要显示名称及等待/成功/失败。展开保留完整参数与结果，不再静默截掉65K之后的证据。跨轮重复callId不会覆盖已有卡片；未配对的调用/结果也保留，重开历史同样配对展示。
- 实际故障记录已证明一次 `list_directory('.')` 成功列出6个文件；后续猜测子目录出现ENOENT，两次读取0字节文件被错误拒绝。空文件读取已按0字节正常结果修复；提示模型列目录先使用实际工作区 `.`，不猜目录、不为单纯列目录无故读取内容。
- 模型循环失败采用安全分类（HTTP、截断、超时、预算等）并在错误文本保留已完成列目录/工具成功失败计数，不输出原始服务错误或凭据。旧日志未记录最终异常，不能据此声称已经确认当时最后一次失败的精确原因。
- 验收采用隔离Electron的DOM边界框、可访问名称、无可见角色标签和卡片参数/结果断言；本轮父审查另查看实际截图，确认输入框没有多余停止/探测/模型工具控件。

## 已有会话切换模型

- 历史结构有效的已索引会话在空闲时可直接选择其他已配置模型；首页与聊天框同步。主进程签发确认弹窗，明确下一次发送会转移完整历史（含工具结果）到新模型/服务；不是静默跨服务发送。
- 取消保持原模型、会话和磁盘历史不变。确认前后校验配置版本、预览 token/期限、会话身份与工具调用配对；忙时拒绝，新 token 会使旧确认失效。索引租约内再检查身份后才持久化目标；不接受渲染器提供任意会话 ID。
- 接受后仍是同一会话/标题/历史，重新打开沿用新目标；当前权限保留，不把模型选择与权限授权混为一项。切换本身不发模型请求，也不改写消息日志。原有发送接口仍拒绝未确认的身份变化。
- 失败只是上轮结果，不锁死会话：失败的已索引聊天可继续或显式切换模型；界面预览截断不改变完整持久历史。结构损坏/未索引历史原地报错，不覆盖、不自动新建。自绘确认不能抵抗已被攻陷的主渲染器。

## 失败与中断留在原聊天

- 超时、停止、模型/工具失败保留同一会话ID和侧栏项；只有显式新建清空当前会话。下一次显式发送携带原有消息，包括失败前已保存的用户输入，不自动重发旧请求。
- 复用 SessionStore.recover：下一次发送前严格检查历史，只追加缺失的工具消息；优先使用已记录真实结果，缺失则标记“结果未知/错误，未重跑”。不调用旧工具、不伪造成功、不回滚文件。恢复和发送保持各自非重入租约，竞争写入仍拒绝。
- 成功响应报告补齐数量；失败提示查看已保存工具历史。重开只读检查，不进行恢复写入。腐坏日志原样保留并拒绝继续。
- 切换目录不自动新建；已有聊天与工作区不匹配时原地报错，恢复原工作区才能继续。刷新渲染器恢复主进程当前聊天。
- 回归：`scripts/verify-provider-settings.cjs` 用隔离 Electron profile 和回环 mock 验证首次回复后切换、取消、token 失效、繁忙拒绝、相同历史、新模型出站、持久索引重开；不触碰用户窗口或真实凭据。

## 真实提供商差异诊断

用户通过本机 8787 网关的 claude-opus-4-8 请求列目录，实际记录仅有文字回复，自称工具为 read_tabular/system_todo_write，没有工具调用。不能据此判断客户端未传 tools，或断言网关丢弃 tools；旧日志没有请求工具清单。独立进程探测因 OS 密钥解密失败未能发出，未读取备用凭据、未改用户配置。

每轮保留本次声明的工具及调用计数，未调用时明确「没有读取项目文件」。此前合成工具探测按钮现已从输入框删除；不以按钮或 HTTP 成功宣称云端工具兼容。用户补充的「已声明五个工具但无调用」排除了该轮工具关闭；仍不证明网关内部丢弃了参数，需要独立协议测试或网关侧证据。

## 核心工具执行链

- [核心工具目录](<../src/core-tools.ts>) 为 CLI 和桌面共用的工厂表，不再各自维护一套文件工具子集。桌面额外保留有界 list_directory；工具结果可能发给所选模型并保存在本地历史。无工作区仍为文字问答，不隐式选择用户目录。
- 工作区文件操作经应用路径检查后自动执行，命令在工作区档逐次询问；完全访问同时放开文件读写范围并免常规命令询问。只读不注册写入和命令工具。CLI 原有档位策略不因桌面改变而静默放宽。
- 桌面采用共享核心预算：每轮最多10步、每步8次/整轮32次工具调用，工具轮期限5分钟。文件写预算仍为3文件/200行，没有随此次接线放宽；不是无限运行。配置以 [desktop-model](<../src/desktop-model.ts>) 与 [runtime](<../src/runtime.ts>) 为准。
- `run_command` 可启动前台命令或后台作业，`job_output`/`job_kill` 只访问当前会话 owner 的作业。Stop、离开会话、新建、切换工作区/权限和窗口关闭会等待清理；正常完成的回复可以保留显式后台作业继续运行，界面仍给出停止入口。
- 取消信号覆盖模型请求、工具审批和注册的进程树；Windows 使用系统 taskkill，Unix 使用进程组，等待关闭结果，清理失败不伪装成功。不能承诺杀掉脱离注册树的进程、撤销既有文件修改或停止上游计费。
- 聊天保留真实参数、结果、拒绝与已执行记录。敏感路径过滤不是内容脱敏，文件保护不是 OS 沙箱；模型 shell 和手动 shell 均拥有当前用户可用的文件/进程/网络权限。
- 技能主入口改为原生文件夹 / ZIP / 单个 SKILL.md 导入，插件保留原始技能、参考资料、脚本、资源和许可；存放于固定 Agent home 下的 plugins/<插件>/<版本>，不跟随所选工作区。一次启用在此 Agent home 的所有工作区可用，不要求手填关键词或优先级。旧版提示词目录与按工作区启用保留兼容，不冒充完整 Skill 包。
- 启用包向模型提供有界名称/描述目录；模型按任务语义选择，通过 skill_read / skill_list_files 逐步读取完整技能和资料。只读档也能读取；普通文件工具仍禁止访问 Agent 状态目录。安装与读取校验完整文件指纹，拒绝链接、ZIP 越界/别名冲突、过大内容及明文凭据配置。不会扫描仓库自动安装，也不会执行导入脚本或继承其工具权限。无工作区的文字问答暂不提供技能读取工具。
- MCP 支持常见 mcpServers JSON 编辑，保存不自动连接。保留本地 stdio（绝对可执行文件，不隐式启动 npx/cmd shell），新增远程 Streamable HTTP，支持 JSON 与 SSE 的 POST 响应；HTTPS 或显式回环 HTTP，无重定向或副作用重试。headers/env 值通过 safeStorage 加密保存，回显为 [REDACTED]，只能在原 ID/传输/地址下保留；不会迁移 TRAE OAuth 登录或使用提供商凭据。支持手动 Bearer/PAT，不含 OAuth 浏览器流程与旧版独立 SSE 传输。
- 连接需显式确认本地命令或远程地址。只读不启动/提供 MCP，工作区写入逐次审批调用，完全访问免常规调用确认。服务器自称 readOnly 不构成授权。连接按窗口/工作区隔离，停止、切换工作区/会话和关闭窗口清理；本地等待进程退出，远程停止不能撤销已发生的服务端操作。不自动重连，远程会话过期需手动重新连接。
- 会话管理：已索引会话支持重命名、组内置顶、确认删除，以及原生保存对话框导出完整有界 Markdown/JSON 消息和工具内容。导出不含审计/提供商配置，拒绝覆盖现有文件及导出到 Agent 状态目录。旧版未索引历史保持只读。删除先在锁内归档并提交索引，索引失败回滚；若归档清理失败明确警告，不声称已永久擦除。

## 计划、长任务与记忆

- 可直接描述任务，由模型根据当前用户意图调用 create_goal 创建目标和验收条件，宿主进行有界续跑；也可点击 /goal 按钮填入命令，或保留原手动面板。无需工作区即可计划/管理目标，没有工作区时不提供本地工具。默认3轮、最多20轮；每轮5分钟、每次连续运行30分钟，权限不因目标而提高。
- /plan 在模型执行前限制为只读规划，生成可编辑的会话计划；待确认时不提供命令/写入/MCP能力且逐调用检查门禁。计划保存在Agent home，不自动写项目目录。面板支持目标/验收条件/计划/预算编辑、确认计划并执行、人工完成和删除记录；修改不重置已用轮数。
- update_goal（兼容task_checkpoint）请求继续、等待输入、待验收或带具体证据说明完成。完成明确标注模型判断而非独立验证；人工验收仍保留。工具失败/拒绝、无报告、重复进度、停止/关闭与预算用完暂停；重启不自动续跑，模型不能恢复人工暂停的目标。输入框下任务条显示进度，运行时点击暂停。无定时队列、自动上下文压缩或无限运行。
- 设置 → 记忆与进化：用户手动保存全局/当前工作区偏好，可改、停用、删除或清空；启用项在下一次发送进入真实模型请求。没有自动采集所有聊天或模型自行写入。删除不撤回历史与提供商已收内容；不能把界面名称“进化”解读为已实现自主学习。

## 插件、技能与连接器

- 设置 → 插件：按插件清单显示包名称、所含技能、连接声明和真实连接状态。GitHub/Cloudflare 可直接「配置连接」填写自备令牌，不必手抄 JSON；保存后再点连接并同意远程访问。远程 HTTP 服务无需选择工作区或开放本地写权限，可多服务同时连接，切换工作区保留连接；本地 stdio 仍受工作区隔离。已连接意味着本窗口的握手及工具发现完成，不是复制了 TRAE 的登录。
- 设置 → 技能（Skills）：逐项展示 Skill 及来源包，保留资料按需读取；目前启停仍以所属包为单位，按钮明确标注。纯 Skill 文件夹不会冒充插件。插件中的技能也可在此找到，无 MCP 的设计类插件无需连接。
- 现支持卡片上的「OAuth 浏览器授权」，保留手动 Bearer/PAT。Cloudflare 使用动态公共客户端注册 + PKCE S256 + 随机本机回调，无需手输令牌；权限可在服务商页选择。GitHub 使用设备码流，已预置发行者提供的公开 Client ID，普通用户无需注册应用或填写 ID；点击后在浏览器登录自己的账号并输入本窗口设备码确认。发行者须保持该 OAuth App 的 Enable Device Flow 开启；未内置 Client Secret，不借用 TRAE、VS Code 身份。
- 按发行者要求，GitHub 授权表单默认请求 read:user repo；repo 包含公有和私有仓库广泛读写权限，非指定仓库或只读，可手动缩小范围。旧授权不自动扩权，需重新授权确认一次；正常“连接”复用已保存令牌，不需要重复设备码授权。组织 OAuth App 审批/SAML 和账户政策仍有效；授权成功不代表所有工具都具备权限。
- 表单点击「打开浏览器授权」即开始，不再重复弹原生确认；未选择工作区/只读也可授权保存。浏览器回调提示仅表示收到回调，最终以客户端“已安全保存”或“已连接”为准。Cloudflare等服务返回的大量权限名称可在16KiB范围内校验保存；输入权限仍限4096字符。交换/保存失败与保存成功但MCP连接失败分别提示。
- 主进程打开系统浏览器，等待至多10分钟，可取消；关闭窗口/刷新/停止也取消。access/refresh token 仅在系统加密凭据中保存，不回传渲染器、不进模型提示或 JSON 导出。JSON 仅以 oauth: [REDACTED] 保留同地址授权；改地址需重新授权。连接前若即将过期且有 refresh token 则刷新并保存轮换值，不会重放失败的工具调用；工具运行中失效需重新连接。
- 「断开」保留加密授权；「清除本地授权」断开并删除本机令牌，不等于服务商已撤销，彻底撤销请去服务商已授权应用页。原宿主 app/CLI 工具和额外 MCP 依赖需自行安装授权，仅当前发现工具可调用。包删除与独立 MCP 配置删除分开。
- 当前通用 OAuth 范围为同源授权服务器元数据、公共客户端 PKCE 和动态注册/自有 Client ID（预注册回调使用 http://127.0.0.1:<动态端口>/oauth/callback，服务须支持原生客户端可变端口）；跨域企业 IdP、需要 client secret 的代码流、客户端元数据文档注册和任意完整 OAuth 发现尚未支持。GitHub 为官方端点专门设备流适配。已验证隔离协议/桌面链路，不声称真实账户授权成功。
- 官方依据：[Cloudflare MCP](https://developers.cloudflare.com/agents/model-context-protocol/cloudflare/servers-for-cloudflare/)、[Cloudflare OAuth 元数据](https://mcp.cloudflare.com/.well-known/oauth-authorization-server)、[GitHub OAuth/设备流](https://docs.github.com/en/apps/oauth-apps/building-oauth-apps/authorizing-oauth-apps)、[GitHub MCP 资源声明](https://api.githubcopilot.com/.well-known/oauth-protected-resource/mcp/)。

## 导入与远程 MCP 使用

- 设置 → 本地技能：点击导入文件夹或选择 ZIP；插件根目录及其中 SKILL.md、references、scripts、assets 一起保存。全局指同一 Agent home，不是对所有软件或其他 home 生效。仅选单个 SKILL.md 时不包含旁边资源，完整技能请选文件夹/ZIP。
- 设置 → MCP 连接器 → 编辑 MCP JSON：例如 GitHub 可填写下面的自备令牌配置。占位文字需换成你本人授权的令牌；保存后仅显示脱敏值，再单独点击连接。不要把真实令牌写进版本库或聊天。GitHub 账号、令牌权限及组织政策需在实际连接时验证；本轮仅使用回环服务验收。

```json
{
  "mcpServers": {
    "github": {
      "type": "http",
      "url": "https://api.githubcopilot.com/mcp/",
      "headers": { "Authorization": "Bearer REPLACE_WITH_YOUR_OWN_TOKEN" }
    }
  }
}
```

- TRAE 插件内的 `${connector.github.ACCESS_TOKEN}` 等是原宿主变量，不是真令牌，不能直接粘贴并期待继承登录。Cloudflare 对应远程地址是 `https://mcp.cloudflare.com/mcp`；所用服务是否接受自备 Bearer 及其权限需单独确认，当前客户端没有 OAuth 登录能力。
