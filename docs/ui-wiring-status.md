# Personal Agent 界面接线清单

范围：本仓库独立 Electron 客户端，不是 DSH GUI。以能实际完成操作为「已接线」，跳转占位页、弹出未实现提示不算接通业务。下表结合代码审计与本轮 Electron 验收；第三方云端兼容性不在回环模拟服务验收范围内。

## 模型文件工具执行链（新增）

- 输入框下方新增独立「模型文件工具」权限：默认关闭；启用只读或逐次确认写入时，明确告知文件内容发送给当前模型服务并保存历史。选择工作区不自动授权模型；切换历史、目录、刷新后重新关闭。
- 已接 `list_directory`、`read_file`，写模式额外接 `create_file`、`edit_file`、`patch_file`。复用现有工具与审批规则，不加载 CLI 权限配置、不继承额外受信读取目录；敏感路径、链接与越界请求拒绝。
- 每轮最多6次模型调用、8次工具调用、每步2个工具、3个写文件/200行写预算，180秒整轮期限。只读模式不注册写工具；写入逐项确认，拒绝结果返回模型。
- 聊天显示执行状态，结束后展示真实工具请求参数与结果，持久历史可重看；失败、停止保留已执行记录。停止按钮可取消请求和待审批操作，但不回滚已经发生的修改。
- 仍无模型命令执行、后台作业、删除/重命名/批量修改、MCP、技能。人工终端权限与模型文件工具互相独立。纯文本的旧测试接口仍不开放工具。
- 文件保护属于应用层策略，不是 OS 沙箱；并发文件变更存在竞态边界，普通文档里的秘密无法由敏感路径过滤自动识别。自绘确认同样不能抵抗已经被攻陷的主渲染器。

## 前一轮补齐的基础接线

| 入口 | 实际行为 | 边界 |
|---|---|---|
| 顶栏任务搜索 / Ctrl+K / 聊天头部历史 | 从真实会话索引按标题、工作区搜索，点击读取对应历史 | 不是聊天全文检索 |
| 任务筛选 | 按索引的完成、未完成/失败、未索引状态筛选 | 失败标记也包含未完成请求，不能冒充运行中状态 |
| 上/下一个会话、定位当前会话 | 操作真实会话行，不再读取空演示列表 | 无会话时不构造假会话 |
| 助理 / 项目 / 我的文件 | 助理回到聊天首页；项目打开本地工作区工具；我的文件打开工作区文件树 | 项目入口只是工作区工具，不是项目 CRUD |
| 命令面板的文件树、终端、浏览器 / 右栏快捷键 | 共用已有真实工作区工具 | 仍是用户手动工具，不向模型授权 |
| 聊天头部复制 / 更多 | 复制当前可见对话；更多提供真实新建、历史、复制操作 | 非在线分享，不创建公开链接；只复制已加载内容 |
| 会话右键 | 打开真实会话、复制标题/会话 ID | 不假装支持重命名、置顶、删除 |
| 编辑菜单 | 经受信主框架 IPC 调用 Electron 撤销、重做、剪切、复制、粘贴、全选 | 严格动作白名单；不接受任意方法或脚本 |
| 主题、字号、发送快捷键、简洁模式 | 实际应用并保存在本机 UI 偏好中，重新加载可恢复 | 仅本机界面偏好，不包含密钥；不是云同步 |
| 个人区更多、帮助、版本/诊断 | 进入真实设置/说明，显示实际桌面版本与隔离信息 | 账号、计费、自动更新、官方支持平台并不存在 |
| 尚未实现的设置 | 标明未实现并阻止假开关误导 | 安全页不再把数据脱敏、OS 沙箱标为已生效 |

## 已接线且此前存在

- **模型提供商**：新增、自定义 OpenAI 兼容地址、编辑、删除、获取模型列表、手填 ID、选模型、safeStorage 加密保存密钥。
- **文字聊天**：真实 HTTP 请求、多轮上下文、新建隔离、JSONL 持久化、安全 Markdown 子集、历史恢复。失败后可输入，下一次发送另建会话；不会自动重放失败请求。模型/配置变化也不会把旧上下文发送给新服务。
- **会话与文件夹侧栏**：从索引恢复目录和真实会话，历史符合身份/成功条件才可续聊；恢复目录一律只读。
- **窗口**：最小化、最大化/还原、重置大小、新窗口、全屏、关闭。侧栏折叠与窄屏抽屉。
- **本地工作区**：原生选择目录、只读文件列表与文本预览、人工单次命令、隔离浏览器的打开/后退/刷新/关闭。
- **权限确认**：客户端内确认弹窗，取消/允许分支；主进程校验窗口来源与待确认请求。注意一次性 ID 只防串请求/重放，不能证明真实用户点击，也不是对渲染器被攻陷的隔离屏障。

## 已有 runtime/CLI 能力，但桌面未接线

| 功能 | 已有实现 | 桌面缺口 |
|---|---|---|
| 模型命令/删除/重命名/批量工具 | [CLI](<../src/cli.ts>) 注册完整工具，[tools](<../src/tools.ts>) 实现执行链 | 桌面 [desktop-model](<../src/desktop-model.ts>) 仅接上述文件工具子集；命令工具的进程树取消和输出限制需独立补强，尚未向模型开放 |
| 技能 | [skill-catalogue](<../src/skill-catalogue.ts>) 的目录/provider 与 [taskspec-prompt](<../src/taskspec-prompt.ts>) 路由 | 桌面 taskPromptSkills=[]；没有目录/安装/启用管理 IPC |
| MCP 连接器 | [mcp-plugin](<../src/mcp-plugin.ts>) 与 [mcp-bridge](<../src/mcp-bridge.ts>)，CLI 加载 stdio 工具 | 没有桌面插件管理、启停、认证和工具调用接线 |
| 长期约束/记忆相关上下文 | [constraints](<../src/constraints.ts>) 与 [runtime](<../src/runtime.ts>)，长期约束会影响桌面提示 | 无桌面读取/编辑；历史摘要、任务状态、经验基因不等于用户记忆管理产品 |
| Token 使用量 | [session-store](<../src/session-store.ts>) totals 与 runtime usage 记录 | 桌面响应未透传用量，状态栏没有统计；不能当成余额/账单 |
| 取消、压缩、恢复诊断 | [interactive](<../src/interactive.ts>) 的 CLI Ctrl+C、inspect/recover/compact | 桌面现有停止 IPC，尚无压缩/修复 IPC；当前请求非流式 |
| 后台作业 | [background-jobs](<../src/background-jobs.ts>) 与 CLI 工具 | 未接桌面后台任务；不等于定时任务 |

## 尚未实现的业务

- 专家/多个助理档案、选择/创建/委派管理（普通聊天首页不算专家产品）。
- 定时任务：计划 CRUD、cron 调度、持久队列、到时触发和重试。
- 应用管理：发布、安装、卸载、运行生命周期。
- 腾讯文档、邮箱、ima、乐享知识库：认证、同步、收发/检索等专用集成。
- 用户账号、登录、个人资料服务、套餐/积分/余额及计费账本。
- 技能市场、自动推荐与安装、图片附件发送、语音录制、@ 选择器、斜杠命令。
- 桌面会话重命名、置顶、删除、公开分享链接、文件导出、全文检索。
- 自动更新发布服务、官方网站/反馈后端；开机自启、代理、通知/提示音、多语言、保留期限清理等设置实际执行链。
- 帮助菜单的资源占用、打开日志目录、开源许可查看器仍未接线；本轮诊断仅展示真实版本/隔离信息，不是日志或性能诊断工具。
- 快捷键自定义、全局唤起/隐藏窗口没有实现。设置页快捷键是固定绑定说明；日常办公/代码开发/设计创意仅切换输入提示，不是 Agent 工作模式。
- OS 级命令沙箱、云端数据自动脱敏/隐私保证；不能仅靠界面开关声明。

## 验收与局限

本轮在现有真实 Electron 回环验收中增加：真实三会话搜索/筛选/导航、工作区菜单入口、编辑动作白名单、UI 偏好保存与重载、发送按键行为、未知配置/占位功能不假装生效。继续保留提供商密钥加密、来源拒绝、失败新会话隔离、工作区/浏览器隔离回归。

本次执行结果：构建通过；全量 811 项测试，810 通过、1 跳过、0 失败；真实 Electron 提供商/聊天/界面接线/工作区验收通过。新增真实模型工具协议回环验收：显式授权、读取文件、只读拒绝伪造写入、批准创建、拒绝修改、停止待审批操作、工具结果历史恢复。工具单测额外覆盖实际 edit/patch、敏感文件/链接/信任根越界、调用与写预算、失败后真实日志保留。故障模拟产生的 chat:send 错误及未知编辑动作拒绝属于预期负向用例。两套 Electron 验收使用独立 user-data-dir，避免改变真实用户偏好。

模型接入仅保证已测的 OpenAI 兼容回环协议，不保证任意云端账号权限。工作区不是操作系统沙箱，完全访问命令可访问工作区外。设置项标为未实现表示其功能仍未接通，而非隐式启用。
