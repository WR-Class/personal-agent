## 安全边界的准确含义

D26 解决的是 **Agent 自身配置不能由仓库自动提权**。它不会阻止 Git、npm 或脚本读取自己的项目配置。Git 仍不进入“只读免审批”白名单；不能把 D26 已完成理解为 Git 可以安全免问。见 [命令规则](../src/tiers.ts) 和 [投毒回归](../test/middle-tier.test.ts)。

文件路径检查、审批、环境收敛和审计均不是操作系统沙箱。获准执行的命令仍可能访问其他位置；并发替换路径（TOCTOU）、非合作进程与不可信插件代码不在已验证保证内。
