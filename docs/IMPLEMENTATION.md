## 0. 项目目标和非目标

目标：独立、可替换模型、可审计/恢复、插件可扩展的个人 Agent；CLI 是首个客户端，未来 UI 不绑死内核。参考 [源码取舍](REFERENCE_DECISIONS.md)，不再凭产品印象选型。

当前已有：Provider/交互CLI、安全只读工具、环境白名单、JSONL字段校验、合作会话锁、有限显式恢复、正常取消。缺少：完整Policy/Approval和Schema、资源预算、事务恢复、写工具、进程沙箱、Skill/插件、多Agent。不要把后者标成已完成。

近期非目标：API 代理网关、完整 IDE、插件市场、多 Agent 并行写入、自动递归清理。

## 3. M2/M3 开始前的硬门槛

- 授权：`模型工具提案 → Schema 校验 → Policy → 必要审批 → Executor → 结果事件`，不得存在第二条直接执行入口。
- 审批绑定工具、canonical 目标、内容/命令、授权范围、有效期；用户拒绝不是“换个工具继续”的信号。
- 文件修改：先读/版本检查，展示 diff，原子替换或明确降级；不自动执行删除目录。
- 进程：白名单环境不足以限制绝对路径，必须验证平台执行约束；平台不支持则禁用危险能力，不静默降级为全权限。
- 测试只对合成数据做越界尝试；不拿真实 .dsh/凭据/用户文档做破坏性验收。
- 任何写工具或 process executor 加入前，由用户确认 M1 验收证据和授权默认值。
